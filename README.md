# EverPT — laboratório Etervale

Este repositório será usado para manter o código do **EverPT**, a implementação experimental do Priston Tale desenvolvida a partir do projeto público [Etervale](https://github.com/bencz-games/Etervale).

## Ambiente de desenvolvimento

- **Servidor de testes:** VM isolada `Etervale-Lab-20261108` no Unraid Ziel.
- **Cliente Windows:** destinado ao Nexus, em `E:\\Etervale-Lab`, depois da validação do servidor e da compilação do runtime MonoGame/Vulkan.
- **Produção:** não alterar a VM Games nem os servidores e clientes do StormPT em produção.
- **Dados de jogo:** arquivo `assets.7z` disponibilizado no README do Etervale. **Não** publicar os assets neste GitHub; direitos de terceiros podem se aplicar.
